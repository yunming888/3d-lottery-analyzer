## 18:40 新增 position_pattern.py：分位×大小形态分析与形态出号（只读诊断 + 规则出号）
- 起因：云明要求「按百/十/个位分析规律、结合大小形态（大大大…小小小 8 种）给出出号方法与参考结果」。
- 分析（500 期合并数据集，截至 2026291）：
  - **8 形态分布无偏离**：近30 χ²=4.13(p=0.77)、近100 χ²=5.28(p=0.63)、全样本 χ²=5.98(p=0.54)。
  - **形态序列无自相关**：8×8 转移 χ²=57.99 df=49 p=0.18。「上期小小大→本期小大小 24.5%（1.96×）」看似强，但**置换模拟 1000 次：纯随机下 64 格最大 lift 中位数 1.86、95% 分位 2.18，观察值 1.96 在第 72 百分位** → 纯噪声（方法论可复用）。
  - **三位独立**：实测形态 vs 边际相乘 χ²=2.91 df=7 p=0.89；两两 p=0.24/0.24/0.69。边际大号率 百 53.8% / 十 50.4% / 个 49.0% → 形态概率=相乘，8 形态全距仅 **11.2%~13.8%（2.6pp）**。
  - 三口径排序互相矛盾（边际 大大小第一 / 近100期 大大大17% / 回摆规则 大小小0.74 压倒）→ 形态不可判。
- **核心结论（务必记住）**：买到号码层面后，命中率恒 = 注数/1000，与押哪个形态无关。8 注=0.8%；买满一块 125 注=12.5%、成本 250 元、12.5%×1040=130<250 → 每期亏 120。形态只决定钱花在哪一块。
- **自我批判（规则缺陷）**：`score_sides` 的遗漏项使「没出的那侧」恒得高分 → 本质是赌徒谬误的机械化，无统计依据。
