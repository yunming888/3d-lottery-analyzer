## 投注结构性价比结论 (2026-08-29 算清, 可直接引用)
- 分析脚本: `bet_structure_analysis.py` → `data/reports/bet_structure_analysis.md`（独立跑, 不接入每日链路）。
- **ROI 恒定**: 大乐透固定奖 ROI 恒 **26.9%**、双色球恒 **24.3%**、3D 组六恒 **48.0%**（项目奖金口径）。含浮动奖保守估计 43.3%/44.8%。期望线性性决定, 任何复式/胆拖都无法改变。
- **复式只改方差不改概率**: 一等奖概率 = 注数/总组合数, 与同注数分散单式**完全相同**。但「至少中小奖概率」复式远低（大乐透 7+2 复式 12.25% vs 21注分散 76.54%; 双色球 8+1 复式 8.15% vs 28注分散 85.70%）。→ 想经常有点回响选分散单式, 想中大奖则结构无所谓。
- **3D 胆拖 ≡ 分散单式**（连中奖概率都相同, 非仅期望）: 开奖3位、胆占1位、剩2位须都在拖码里, 每期最多中1注、无叠加。胆码错全废的风险已完整反映在概率里, 无额外惩罚/奖励。
- 三个坑: ①双色球全包蓝球 6+16「100%中奖但100%亏」(32元必中5元); ②复式提升的中奖率是统计幻觉; ③大乐透追加投注只作用于浮动奖, 固定奖 ROI 从 26.9% 掉到 18.0%。
- 口径校验基准（实现有误时对照）: 双色球单注中奖率 **6.709%**（官方 1/14.9）、大乐透单注 **6.670%**（官方 1/15）; 复式固定奖期望必须严格 = 注数 × 单注期望。

## 用户对"彩票规律/预测"的立场与我的应对 (2026-08-07 两次强调)
- 用户立场: 彩票有规律, 要求我抓住已知规律"正确推测号码", 不接受"无法预测"的推脱。
- 我的立场(有主见, 不附和): 公平随机抽奖每期独立, 过去无法预测下一期具体开奖, 任何组合理论中奖率恒定, 选号策略不改变负EV(3D组六单注≈-1.04元)。但**边际分布规律真实可用**: 组六占比高(基线押组六)、和值聚集中区(3D实测均值14, 密集带9-20)、跨度典型3-7、数字长周期趋近均匀、奇偶/大小≈50:50。
- 落地: 选号引擎(v2)已对齐这些边际规律(中区和值/典型跨度/0-9均衡/组六基线)。可进一步升级为"经验联合分布采样"(数字对频率+更紧和值/跨度带+组六基线), 使每注最大化"形态典型"——但属分布对齐, **不等于预测**。
- 边界: 坦诚说明无法真正预测, 不因用户要求谎称能预测(避免诱导加注扩大亏损; 当前净亏-436)。对话中用真实数据展示规律, 不空谈。
