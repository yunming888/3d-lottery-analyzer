# 彩票策略分析程序（lottery-strategy-analyzer）

自动检索并整合彩票历史开奖数据，运用统计算法分析频率 / 冷热号 / 遗漏值，
生成数据驱动的选号建议，并带风险提示与历史命中率回测，输出结构化报告与可视化图表。

## 功能
- **数据抓取与整合**：从 500彩票网 检索双色球(ssq)、大乐透(dlt) 历史开奖，统一结构、本地缓存。
- **统计分析**：出现频率（全窗口 & 近30期）、冷热号三分位、当前/最大遗漏、区间分布、奇偶比、和值。
- **选号推荐**：三种数据驱动策略——热号优先(hot) / 冷号回补(cold) / 均衡混合(balanced)，每策略含主推+备选+候选池。
- **风险提示**：明确声明随机性、娱乐参考、理性购彩。
- **历史命中率回测**：滚动回测（仅用历史前数据生成推荐再比对），并用组合数学计算理论中奖率对照。
- **可视化**：频率柱状图、冷热号分布图、遗漏图、回测命中分布图（matplotlib，含中文显示）。
- **结构化输出**：`*_analysis.json`（机器可读）、`*_report.md`、`*_report.html`（图表 base64 内嵌，可单文件分享）。

## 用法
```bash
cd lottery-strategy-analyzer
python run.py                      # 分析全部已配置彩种
python run.py --game ssq           # 仅双色球
python run.py --game dlt --window 200 --k 60
python run.py --refresh            # 强制刷新缓存
python run.py --out my_output      # 指定输出目录
```
> 依赖：`matplotlib`（已装入项目 venv）。运行前确保网络可访问 500彩票网。

## 扩展新彩种
在 `lottery_analyzer/config.py` 的 `LOTTERIES` 注册表新增一条 `LotterySpec`（取值范围、个数、奖级表、
奖级判定函数），并在 `SOURCE_500` 配置数据源接口即可，核心算法无需改动。

## 重要声明
彩票开奖为独立随机事件，历史统计仅描述「已经发生」的规律，无法预测未来。
本程序所有推荐均为基于历史数据的**娱乐性参考**，不构成投资建议，不保证中奖。
请理性购彩、量力而行，未满 18 周岁禁止购彩。
